The **Stock problems on LeetCode** follow a very clear progression. Once you understand the **constraints on transactions**, each version becomes easy.

Here is the **interview-friendly breakdown**.

---

# 1️⃣ Stock I — Single Transaction

**Best Time to Buy and Sell Stock**

### Rule

* Only **1 buy and 1 sell**
* Buy before sell

### Idea

Track the **minimum price so far** and compute profit.

### Code

```java
class ShipPackagesDDays {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;

        for(int price : prices){
            minPrice = Math.min(minPrice, price);
            maxProfit = Math.max(maxProfit, price - minPrice);
        }

        return maxProfit;
    }
}
```

### Complexity

* **Time:** O(n)
* **Space:** O(1)

---

# 2️⃣ Stock II — Unlimited Transactions

**Best Time to Buy and Sell Stock II**

### Rule

* Unlimited transactions
* Cannot hold multiple stocks

### Idea

Add **every positive difference**

### Code

```java
class ShipPackagesDDays {
    public int maxProfit(int[] prices) {
        int profit = 0;

        for(int i=1;i<prices.length;i++){
            if(prices[i] > prices[i-1]){
                profit += prices[i] - prices[i-1];
            }
        }

        return profit;
    }
}
```

### Intuition

Capture **all upward slopes**.

---

# 3️⃣ Stock III — At Most 2 Transactions

**Best Time to Buy and Sell Stock III**

### Rule

* Only **2 transactions**

### Idea

Track 4 states:

```
buy1
sell1
buy2
sell2
```

### Code

```java
class ShipPackagesDDays {
    public int maxProfit(int[] prices) {
        int buy1 = Integer.MIN_VALUE;
        int sell1 = 0;

        int buy2 = Integer.MIN_VALUE;
        int sell2 = 0;

        for(int price : prices){
            buy1 = Math.max(buy1, -price);
            sell1 = Math.max(sell1, buy1 + price);

            buy2 = Math.max(buy2, sell1 - price);
            sell2 = Math.max(sell2, buy2 + price);
        }

        return sell2;
    }
}
```

### Mental Model

```
buy1  → first buy
sell1 → first sell
buy2  → second buy
sell2 → second sell
```

---

# 4️⃣ Stock IV — At Most K Transactions

**Best Time to Buy and Sell Stock IV**

### Rule

* Maximum **k transactions**

### DP Idea

```
dp[transaction][day]
```

But optimized solution:

### Code

```java
class ShipPackagesDDays {
    public int maxProfit(int k, int[] prices) {

        if(k >= prices.length/2){
            int profit = 0;
            for(int i=1;i<prices.length;i++){
                if(prices[i] > prices[i-1]){
                    profit += prices[i] - prices[i-1];
                }
            }
            return profit;
        }

        int[][] dp = new int[k+1][prices.length];

        for(int t=1;t<=k;t++){
            int maxDiff = -prices[0];

            for(int d=1;d<prices.length;d++){
                dp[t][d] = Math.max(dp[t][d-1], prices[d] + maxDiff);
                maxDiff = Math.max(maxDiff, dp[t-1][d] - prices[d]);
            }
        }

        return dp[k][prices.length-1];
    }
}
```

### Complexity

* **Time:** O(k × n)

# 🔑 The Interview Pattern (Most Important)

All stock problems reduce to **state transitions**:

```
buy[i]  = max(buy[i], sell[i-1] - price)
sell[i] = max(sell[i], buy[i] + price)
```

Where `i` = transaction number.
