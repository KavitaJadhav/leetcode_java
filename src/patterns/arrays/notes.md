
Important distinction

| Concept           |     Number |
| ----------------- | ---------: |
| Subarrays         | `N(N+1)/2` |
| Subsequences      |      `2^N` |
| Subsets           |      `2^N` |
| Non-empty subsets |  `2^N - 1` |

Subarray → contiguous

Subset → any elements, order doesn't matter

Subsequence → any elements, but relative order is preserved.
